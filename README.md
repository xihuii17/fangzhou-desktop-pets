## 安装与升级

- **Windows：**下载 EXE 并运行安装。安装包未进行 Authenticode 签名，系统可能显示未知发布者；请确认来源并核对 SHA-256，不要关闭系统安全防护。
- **macOS：**打开 DMG，把应用拖入 Applications。应用未做 Developer ID 公证；首次打开若被拦截，请确认来源后按照“系统设置 → 隐私与安全性”中的提示操作。
- **Android：**下载 APK，在系统提示中仅允许当前安装来源安装应用；打开后授予悬浮窗权限。最低 Android 9（API 28）。本批 APK 使用调试证书签名。
- **升级前：**在旧版设置中导出陪伴存档，退出旧版后安装相同角色、相同陪伴版。不要删除应用数据。Android 覆盖升级必须保持包名和签名。安卓与桌面存档暂不互通。

更多说明见 [安装与升级](INSTALL.md)。GitHub 自动生成的 Source code ZIP/TAR 不是安装包。
