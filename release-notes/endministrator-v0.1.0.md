# 管理员桌宠（双形态）0.1.0

管理员桌宠双形态通用版的首次独立公开下载版本，整合 348 个动作，可在不带面罩和带面罩形态之间切换，并提供点击互动、随机动作、动作管理与本地设置。

## 下载文件

- `管理员桌宠-通用版-macOS-0.1.0.dmg`
- `管理员桌宠-通用版-Windows-0.1.0-安装包.exe`
- `管理员桌宠-通用版-Windows-0.1.0-免安装版.zip`

文件大小和 SHA-256 见 [安装包清单](../RELEASE_MANIFEST.md)。

## 支持系统

- macOS 11+，Apple Silicon（arm64）
- Windows 10/11，x64

## 已知问题

- 安装包未做商业代码签名，首次打开可能出现系统安全提示。
- macOS 暂无 Intel 版本，Windows 暂无 ARM64 原生版本。
- 双形态版本包含两套动作素材，因此文件体积明显更大。

本 Release 只包含通用版，不包含 AI 版、养成测试版或其他实验构建。
