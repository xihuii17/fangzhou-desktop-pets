# 庄方宜桌宠 0.7.3

庄方宜桌宠通用版的首次独立公开下载版本，包含 162 个内置动作、点击互动、随机动作、动作管理与本地设置。macOS 版本可由用户主动开启 QQ 音乐同步歌词。

## 下载文件

- `Zhuang-Fangyi-Desktop-Pet-General-macOS-0.7.3.dmg`
- `Zhuang-Fangyi-Desktop-Pet-General-Windows-0.7.3-Setup.exe`
- `Zhuang-Fangyi-Desktop-Pet-General-Windows-0.7.3-Portable.zip`

文件大小和 SHA-256 见 [安装包清单](https://github.com/xihuii17/fangzhou-desktop-pets/blob/main/RELEASE_MANIFEST.md)。

## 支持系统

- macOS 11+，Apple Silicon（arm64）
- Windows 10/11，x64

## 已知问题

- 安装包未做商业代码签名，首次打开可能出现系统安全提示。
- macOS 暂无 Intel 版本，Windows 暂无 ARM64 原生版本。
- QQ 音乐同步歌词仅支持 macOS，默认关闭，并依赖辅助功能权限、QQ 音乐和歌词服务可用性。

本 Release 只包含通用版，不包含 AI 版、养成测试版或录制体验版。
